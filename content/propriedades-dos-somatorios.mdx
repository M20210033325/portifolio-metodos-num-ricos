O somatório é expresso pela letra grega sigma (**Σ**), com o limite inferior
indicado abaixo do símbolo e o limite superior indicado acima. O termo à
direita do símbolo é a expressão que está sendo somada.

Basicamente, soma-se todos os termos começando pelo valor do limite inferior
até o limite superior.

## Forma geral

```
  n
  Σ  xi  =  x1 + x2 + x3 + ... + xn
 i=1
```

## Exemplo 1

```
  5
  Σ  2·i  =  2·1 + 2·2 + 2·3 + 2·4 + 2·5  =  2 + 4 + 6 + 8 + 10  =  30
 i=1
```

## Exemplo 2

```
  3
  Σ  i²·(i+1)  =  0²·(0+1) + 1²·(1+1) + 2²·(2+1) + 3²·(3+1)
 i=0
             =  0 + 2 + 12 + 36  =  50
```

## 1ª propriedade — constante no somatório

Quando o termo somado é uma constante (não depende de `i`), o somatório dela
é a constante multiplicada pela quantidade de termos.

<Note label="atenção">
  Se o limite inferior for 1, a quantidade de termos é simplesmente n. Se for
  diferente de 1, use K · (n − i + 1) para contar quantos termos existem de
  fato.
</Note>

```
  n
  Σ  K  =  K · (n − i + 1)
 i=1
```

Exemplo com limite inferior 1:

```
  4
  Σ  0,5  =  0,5+0,5+0,5+0,5  =  2   (4 × 0,5)
 i=1
```

Exemplo com limite inferior diferente de 1 — repare que **não** é
simplesmente 6 × 0,5:

```
  6
  Σ  0,5  =  0,5+0,5+0,5+0,5  =  2   ≠   6 · 0,5
 i=3
```

## 2ª propriedade — somatório de uma soma

Se a expressão somada é uma soma de dois termos, o somatório pode ser
separado em dois somatórios independentes.

```
  m                  m         m
  Σ  (Xi + Yi)  =    Σ  Xi  +  Σ  Yi
 i=1                i=1       i=1
```

Prova direta, expandindo os termos:

```
  m
  Σ  (Xi + Yi)  =  (X1+Y1) + (X2+Y2) + ... + (Xm+Ym)
 i=1
              =  (X1+X2+...+Xm) + (Y1+Y2+...+Ym)
```

## 3ª propriedade — constante multiplicando

Se uma constante multiplica todos os termos do somatório, ela pode sair do
somatório e multiplicar o resultado no final.

```
  m            m
  Σ  K·Xi  =  K · Σ  Xi
 i=1          i=1
```

```
  = K·X1 + K·X2 + K·X3 + ...
  = K·(X1 + X2 + X3 + ...)
```

## 4ª propriedade — quebra de intervalo

Somar de 1 até p, e depois somar de p+1 até n do mesmo termo, dá o mesmo
resultado que somar direto de 1 até n.

```
  p         m              m
  Σ  Xi  +  Σ  Xi     =    Σ  Xi
 i=1       i=p+1          i=1
```

```
= (X1+X2+...+Xp) + (Xp+1+Xp+2+...+Xm)
```

## 5ª propriedade — soma telescópica

Quando os termos vão se cancelando — o termo negativo de um cancela com o
termo positivo do próximo — sobra só o primeiro e o último termo da
sequência.

```
  n
  Σ  (Xi − Xi-1)  =  Xn − Xk-1
 i=k
```

Exemplo:

```
  4
  Σ  (Xi − Xi-1)  =  (X3−X2) + (X4−X3)  =  X4 − X2
 i=3
```

## 6ª propriedade — somatório duplo separável

Se o termo do somatório duplo é um produto de uma parte que só depende de
`i` com uma parte que só depende de `j`, o somatório duplo se separa em dois
somatórios simples multiplicados entre si.

```
  m    n                m          n
  Σ    Σ  Xi·Yj   =     Σ  Xi   ·  Σ  Yj
 i=1  j=1              i=1        j=1
```

Exemplo:

```
  2    2                2         2
  Σ    Σ  i·j    =      Σ  i   ·  Σ  j    =  (1+2)·(1+2)  =  9
 i=1  j=1              i=1       j=1
```

## 7ª propriedade — limite único

Caso os limites inferior e superior sejam iguais, o resultado do somatório é
simplesmente esse número — não tem soma acontecendo, é um termo sozinho.

```
  m
  Σ  xi  =  xm
 i=m
```

## 8ª propriedade — translação de índice

Se somar `p` nos dois limites (inferior e superior), precisa compensar
subtraindo `p` do índice dentro do termo, pra continuar somando os mesmos
valores.

```
  n            n+p
  Σ  xi   =    Σ    xi-p
 i=m          i=m+p
```

## 9ª propriedade — índice livre

Isso acontece quando, num somatório duplo, um dos índices fica livre —
valendo pra qualquer valor de 1 até m, sem ser somado. Nesse caso, separamos
as somas por linha.

```
  n
  Σ  xij  ,  para todo i = 1, ..., m
 j=1
```

## Exemplos práticos

Pra fixar as propriedades, considere as sequências abaixo, todas com 6
termos:

```
x = (x1, x2, x3, x4, x5, x6) = (3, -1, 4, 2, 5, 6)
y = (y1, y2, y3, y4, y5, y6) = (1, 6, -2, 4, 3, 5)
```

E, pro exemplo de índice livre, a matriz:

```
      | 2  -1   3   0 |
M  =  | 1   4   0   2 |
      | -3  2   1   5 |
```

**Soma e diferença** — separando `Σ(xi+yi)` em dois somatórios:

```
  4
  Σ  (xi + yi)  =  (x1+x2+x3+x4) + (y1+y2+y3+y4)
 i=1
              =  (3-1+4+2) + (1+6-2+4)  =  8 + 9  =  17
```

Confere direto, somando termo a termo: (3+1)+(-1+6)+(4-2)+(2+4) = 4+5+2+6 = 17.

**Constante multiplicando** — tirando o 4 do somatório:

```
  4                4
  Σ  4·xi   =  4 · Σ  xi   =  4 · (3-1+4+2)  =  4 · 8  =  32
 i=1              i=1
```

**Decomposição do intervalo** — quebrando a soma de 1 a 6 em duas partes:

```
  6         3         6
  Σ  xi  =  Σ  xi  +  Σ  xi  =  (3-1+4) + (2+5+6)  =  6 + 13  =  19
 i=1       i=1       i=4
```

Confere com a soma direta de todos os 6 termos: 3-1+4+2+5+6 = 19.

**Limite único** — quando o intervalo é um único índice:

```
  5
  Σ  yi  =  y5  =  3
 i=5
```

**Translação de índice** — deslocando os limites em 2 e compensando no
índice:

```
  4              6
  Σ  xi    =     Σ    xi-2   =  x1+x2+x3+x4  =  3-1+4+2  =  8
 i=1            i=3
```

Os dois lados somam exatamente os mesmos quatro termos (x1 a x4) — só muda
a "numeração" usada pra contar até eles.

**Índice livre** — somando cada linha da matriz M separadamente (o índice
`i` da linha fica livre, só `j` é somado):

```
  4
  Σ  Mij  ,  para todo i = 1, 2, 3
 j=1
```

```
linha i=1:  2 + (-1) + 3 + 0   =  4
linha i=2:  1 + 4 + 0 + 2      =  7
linha i=3:  -3 + 2 + 1 + 5     =  5
```

Cada linha vira um resultado próprio — não dá pra colapsar num número só,
porque o valor depende de qual linha (`i`) você escolhe.
